# AgriMonitor

AgriMonitor is a smart agriculture monitoring dashboard designed for farmers to keep track of field conditions, soil moisture, and irrigation recommendations in real time.

## Features

- Real-time field monitoring dashboard
- Soil moisture tracking
- Temperature and humidity display
- Irrigation recommendations and alerts
- Multi-field overview with crop status
- Mobile-friendly responsive layout

## Tech stack

- React
- Vite
- CSS

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local app in your browser at `http://localhost:3000`

## Production build

```bash
npm run build
```
